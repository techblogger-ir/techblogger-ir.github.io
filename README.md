# TechBlogger IR 🚀

مرجع رتبه‌بندی، دسته‌بندی و تحلیل پیج‌های فعالان و تولیدکنندگان محتوای تکنولوژی ایران.

🔗 **آدرس وب‌سایت آنلاین:** [techblogger-ir.github.io](https://techblogger-ir.github.io)

## امکانات پلتفرم
- 📊 مرتب‌سازی و رتبه‌بندی بر اساس فالوور، نرخ تعامل (Engagement) و امتیاز کیفی
- 🔍 جستجوی بلادرنگ در میان اسامی، آیدی‌های شبکه‌های اجتماعی و تگ‌های تخصصی
- 📑 آنالیز عمیق هر پیج (نقاط قوت، توالی انتشار، فرمت‌های پربازدید و تحلیل احساس مخاطبان)
- 🎯 دسته‌بندی بر اساس حوزه‌های هوش مصنوعی، موبایل و گجت، وب، دیتا و آموزش
